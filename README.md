# 外媒发稿统计助手

输入企业/品牌/人物名称 + 日期范围，一键搜索全网媒体发稿，自动分类统计并导出。

---

## 🚀 快速开始

### 前提准备（只需一次）

1. **安装 Node.js**（如已安装可跳过）
   - 访问 https://nodejs.org/ 下载安装

2. **配置 API Key**（可选）

   系统已内置 DeepSeek API Key ✅，可以直接使用。
   
   百度新闻搜索 + 搜狗微信搜索均为免费，**无需任何额外注册或信用卡**。

### 每次使用

| 系统 | 操作 |
|------|------|
| **Mac** | 双击 `启动.command` |
| **Windows** | 双击 `启动.bat` |

浏览器自动打开 `http://localhost:3000`，输入关键词和日期范围，点击搜索即可。

---

## ✨ 功能

- 🔍 **双引擎搜索**：百度新闻（主力，免费）+ 搜狗微信搜索（微信补充）
- 📊 **自动分类**：6 级媒体分类（人民日报/央视 → 央广 → 中央级 → 省部级 → 地方 → 行业）
- 🤖 **AI 兜底**：未识别媒体自动调用 DeepSeek 智能分类
- 📋 **结果去重**：基于 URL + 标题相似度的双重去重
- 📈 **统计摘要**：各类别发稿数量一目了然
- 📥 **一键导出**：CSV 格式，Excel 可直接打开
- 🔗 **直达链接**：每条结果可点击跳转原文

## ❓ 常见问题

**Q：搜索没结果怎么办？**
A：1) 检查 `.env.local` 中 Bing API Key 是否配置正确；2) 尝试更换关键词或扩大日期范围。

**Q：微信搜索结果很少？**
A：搜狗微信搜索有反爬限制，且只返回近期热门文章。如被拦截，微信搜索会静默跳过，不影响 Bing 搜索功能。

**Q：媒体分类不准确？**
A：系统采用"数据库匹配 + AI 兜底"双重分类。可以在 `data/media-database.ts` 中添加或修正映射。
